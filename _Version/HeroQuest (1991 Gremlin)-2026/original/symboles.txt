# Symboles de QUEST.EXE (image mémoire décompressée, IP = position, DS = 0x97C0).
# Une ligne par symbole : adresse  type  nom  commentaire
#   type : code (routine), etiq (étiquette dans une routine), var (variable en DS), table (table en DS)
#   adresse : hexadécimal ; pour var et table, offset dans DS.
# Enrichir ce fichier au fil de l'étude, puis relancer outils/desassembler.py.
