# Symboles de INTRO.EXE (image mémoire décompressée ; adresses = positions dans l'image, CS:0 = 0x44B0).
# Même format que symboles.txt. DS = 0 : l'offset DS d'une variable est sa position dans l'image.
# Ce que fait le programme : original/notes/04-intro.md.

# ---- Déroulé
0x44b0  code  demarrage_intro        point d'entrée : réduit la mémoire (int 21h AH=4Ah), lit QUEST.CFG ; présent : « Press S to change config » (S l'efface) ; absent : questions (écran, son, commandes des 4 héros) ; mode vidéo, son, intro VGA ou EGA/Tandy ; première configuration : drapeaux et écriture de QUEST.CFG ; quitte (code 0)
0x4739  etiq  fin_intro              relit QUEST.CFG : présent, on quitte ; absent (nouvelle configuration), écran des drapeaux
0x4758  etiq  ecran_drapeaux         FLAGS.EGA en mode EGA, même en VGA (mode gardé en DS:10A2) ; touches E F S G I -> langue 0 à 4 ; écrit QUEST.CFG ; vérifie QUEST.EXE (« Insert disk 2 »)
0x4876  etiq  quitte_intro           remet int 9, arrête le son (son_arret), mode texte 3, int 21h AH=4Ch
0x4887  etiq  intro_ega              EGA et Tandy : SHOPMP.EGA et BORDERED.EGA, puis copyright, crédits et les 6 textes, sans animation
0x4912  code  ecran_texte_ega        EGA/Tandy : fond BORDERED (Tandy : rempli de CCh), écusson SHOPMP si BP = texte_copyright, texte BP, copie à l'écran, palette, attend Espace ou Échap (AL = 1 si Échap)
0x4980  code  copie_ecran_ega        tampon 0A86:0 vers l'écran : EGA, 4 plans de 40 × 200 octets (port 3C4h) ; Tandy, 32 Ko vers B800h
0x49e2  code  palette_ega            registres de palette (int 10h AX=1002h) : DS:105E en EGA, DS:106F en Tandy
0x49fc  code  palette_ega_noire      registres de palette à zéro (DS:0C5E) : écran noir avant de dessiner

0x4b80  code  scene_finale           scène 6 (HERO7) : 8 images 16 × 16, attend 60 trames, 10 images en (65, 120) qui finissent en boucle sur 6-7, attend 60 trames

0x4cd3  code  anime_64x64            même chose en 64 × 64 (scène 3)

0x4ddc  code  convertit_64x64        même conversion, images 64 × 64 (plans de 200h octets)

0x4fed  code  affiche_tandy          mode 4 seulement (écran des drapeaux) : tampon 0A86 (rangée de 160 octets = 4 plans de 40) -> 4 bits par pixel en B800h, 4 banques de 2000h ; boucle déroulée, compteur de rangées en CS:23EF (image 0x689F)

# ---- Texte
0x6a3c  code  affiche_chaine         chaîne DS:BP terminée par 0, chaque caractère passé à affiche_caractere
0x6a4b  code  affiche_caractere      caractère AL en police 8 × 8 (DS:13B5) à colonne_texte, ligne_texte ; une routine par mode (table DS:19DC) ; codes 1 = segment (mot suivant), 10h = couleurs (encre, fond), 11h = position (ligne, colonne), 12h = position (colonne, ligne + 4)
0x6a63  etiq  caractere_tandy        mode 4 : glyphe en 4 bits par pixel (pixels_tandy), 4 banques de 2000h ; code 10h : couleur 38h remplacée par 5
0x6ba0  etiq  caractere_ega          mode 6 : glyphe sur 4 plans ; à l'écran (A000h) par les ports 3CEh/3C4h, sinon dans un tampon de 4 plans de 40 octets par rangée
0x6d7c  etiq  caractere_vga          mode 8 : un octet par pixel, ligne de texte = A00h octets ; texte_inverse bit 0 inverse le glyphe, texte_transparent = 1 laisse le fond
